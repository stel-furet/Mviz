Core Features

  • Audio Input System - Microphone and playlist support
  • Multiple Visualization Modes - Spectrum, Mirror Wave, LED, Stereo, etc.
  • Kaleidoscope Effects - Advanced visual effects
  • Infinite Zoom - Dynamic zoom effects
  • Background Image Support - Custom backgrounds with effects
  • Video Input Integration - Live video source support
  • Recording System - Canvas recording capabilities
  • Live Display - WebRTC streaming to external displays
  • Theme System - Steel Gray, Sunset, Aurora themes
  • Playlist Management - File management and metadata parsing

Planned Features

  • Enhanced AI Autopilot - Advanced audio analysis and decision making
  • Scenes System - Complete workspace state management
  • Multiple External Displays - WebRTC streaming to multiple outputs
  • DMX Copilot - Lighting control integration
  • MIDI Copilot - MIDI controller integration
  • OSC System - Open Sound Control protocol
  • Timeline Editing - Effects and settings automation
  • New Visualizations - Liquid Metal, Fire, Particles, Fractals
  • Wireless Display Support - Miracast, AirPlay, Chromecast
  • iPad Version - Touch-optimized interface
  • Electron Desktop - Native desktop application
  • Professional Video Protocols - Syphon, Spout, NDI
