Application Overview

Vizzy is an advanced music visualizer with live display capabilities, multiple visualization modes, and professional features for live performance and studio use.

Key Features

  • Audio Input System - Microphone and playlist support
  • Multiple Visualization Modes - Spectrum, Mirror Wave, LED, Stereo, etc.
  • Kaleidoscope Effects - Advanced visual effects
  • Infinite Zoom - Dynamic zoom effects
  • Background Image Support - Custom backgrounds with effects
  • Video Input Integration - Live video source support
  • Recording System - Canvas recording capabilities
  • Live Display - WebRTC streaming to external displays
  • AI Autopilot - Automated visualization management
  • Theme System - Steel Gray, Sunset, Aurora themes
  • Playlist Management - File management and metadata parsing

Visualization Modes

Spectrum Modes

  • Mode 0 - Spectrum: Classic frequency spectrum bars
  • Mode 1 - Mirror Wave: Dual-vertical mirrored visualization
  • Mode 2 - Classic LED: LED-style bar display
  • Mode 3 - Stereo: Left/right channel separation
  • Mode 4 - Radial Spectrum: Circular frequency display
  • Mode 5 - Energy: Energy-based visualization
  • Mode 6 - Mirror: Horizontal mirroring effects

Advanced Effects

  • Infinite Zoom: Dynamic zoom with audio-reactive objects
  • Kaleidoscope: Mirror and kaleidoscope transformations
  • Background Effects: Image/video backgrounds with filters
  • Morphing: Smooth transitions between visualization modes

AI Classes

AIAutopilot audio-system.js

AI Autopilot Controller - Main AI system that orchestrates automated visualization management. Integrates multiple AI components including audio analysis, decision making, parameter control, and pattern learning. Manages autopilot settings like scope (bars/radial/energy/all), sensitivity levels, and change timing. Coordinates between reactive, predictive, and strategic decision layers to make intelligent choices about visualization modes, parameters, and effects based on real-time audio analysis.

makeAdvancedDecisions()
Main decision-making method that analyzes audio features and executes intelligent changes
setIntensity()
Sets autopilot intensity level (low/medium/high) affecting decision frequency and aggressiveness
setScope()
Sets autopilot scope to control which visualization modes it can change
toggleAutopilot()
Enables/disables autopilot system and manages decision-making loop

Streaming Classes

StreamManager main.js

WebRTC Streaming Controller - Manages live display streaming to external windows via WebRTC. Handles peer connection setup, ICE candidate negotiation, canvas capture, and real-time video streaming. Creates composite canvas that captures all visualization layers, sets up high-quality video encoding parameters, and manages communication between main window and display window through BroadcastChannel API. Supports multiple display windows and configurable streaming quality settings.

startStreaming()
Initiates WebRTC peer connection, creates capture canvas, and starts real-time streaming to display window
setupCaptureCanvas()
Creates composite canvas that captures all visualization layers for streaming output
stopStreaming()
Stops streaming, closes peer connections, and cleans up all resources
handleIceCandidate()
Processes ICE candidates for WebRTC connection establishment
startCapture()
Begins continuous canvas capture and streaming animation loop

Key Dependencies:

WebRTC API BroadcastChannel API Canvas Capture Stream
RecordManager main.js

Recording System - Handles video/audio recording of the visualization canvas using MediaRecorder API. Creates composite canvas that captures all visualization layers including background images, video inputs, spectrum visualizations, and effects. Manages recording quality settings, file format selection, and automatic file saving. Supports both video-only and video+audio recording with configurable bitrates and frame rates.

startRecording()
Begins recording with MediaRecorder API, sets up composite canvas and audio streams
compositeFrame()
Composites all visualization layers (background, video, spectrum, effects) for recording output
stopRecording()
Stops recording, processes final video file, and triggers download
setupCompositeCanvas()
Creates high-resolution composite canvas for recording capture
getAudioStream()
Captures audio stream from Web Audio API for video+audio recording
updateTimer()
Updates recording timer display and manages recording duration

Key Dependencies:

MediaRecorder API Canvas 2D Context Web Audio API File System Access API
